# PiEEG Hardware

Complete hardware documentation for the PiEEG biosignal device family — from 8-channel Raspberry Pi, Arduino, STM32, and Jetson Nano shields to wireless BLE/ESP32 wearables, VR/XR neural interfaces, 32-channel research systems, accessories, and signal-quality guidance.

<Callout type="info">
  All PiEEG hardware is designed for research, education, and prototyping purposes only. Review [Safety & Liabilities](/hardware/safety) before connecting electrodes.
</Callout>

## Hardware Lineup

| Device | Channels | Platform / Connectivity | Signals | Key Specs |
|---|---|---|---|---|
| [**PiEEG-8**](/hardware/devices/pieeg-8) | 8 | Raspberry Pi 3/4/5 (SPI) | EEG, EMG, ECG | 24-bit, 250 SPS–16 kSPS, programmable gain 1–24, impedance check |
| [**PiEEG-16**](/hardware/devices/pieeg-16) | 16 | Raspberry Pi 5 (SPI) | EEG, EMG, ECG | 24-bit, 250 SPS–16 kSPS, programmable gain 1–24, impedance check |
| [**JNEEG**](/hardware/devices/jneeg) | 8 | NVIDIA Jetson Nano (SPI) | EEG, EMG, ECG | 24-bit, 250 SPS–16 kSPS, ML/DL on-device processing |
| [**ardEEG**](/hardware/devices/ardeeg) | 8 | Arduino UNO R4 WiFi (SPI) | EEG, EMG, ECG | 24-bit, programmable gain 1–24, ultra-low power wearable |
| [**MicroBCI**](/hardware/devices/microbci) | 8 | STM32 NUCLEO-WB55 (SPI / BLE) | EEG, EMG, ECG | 24-bit, 250 SPS, programmable gain 1–24, Python + Mobile SDK |
| [**IronBCI**](/hardware/devices/ironbci) | 8 | Standalone Wearable (BLE 5) | EEG, EMG, ECG | 24-bit, 250 SPS, 50 mm diameter, Python + Android SDK |
| [**IronBCI-32**](/hardware/devices/ironbci-32) | 32 | STM32H7 (USB Serial) | EEG, EMG, ECG | 4× AD7771 ADCs, 512 SPS/ch, BrainFlow integrated |
| [**Octopus 16**](/hardware/devices/Octopus_16) | 16 | Seeed XIAO ESP32-S3 (BLE) | EEG, EMG, ECG | 2× ADS131M08 24-bit ADCs, battery-powered, PiEEG Cloud ready |
| [**PiEEG XR**](/hardware/devices/PiEEG_XR) | 8 | VR Headset Face Gasket (BLE 5) | EEG, EMG | Dry electrodes, 24-bit, 250 SPS, Focus-to-Action & avatar EMG |
| [**Aura VR**](/hardware/devices/Aura_VR) | 8 | VR Headset Integration (BLE) | EEG, EMG | Spatial computing neural interface for VR workflows |
| [**OctoBio Kit**](/hardware/devices/OctoBio_Kit) | 16 | Octopus 16 + Arduino Starter Kit | EEG | Classroom-ready kit with browser block coding at octobridge.pieeg.com |

## Support

All scripts, software, datasets, and manuals are available from the [PiEEG Club GitHub](https://github.com/pieeg-club). For questions, use the PiEEG [Discord](https://discord.gg/5Ps24p47).

All 3D models in STL format for 3D printing are available on [PiEEG Thingiverse](https://www.thingiverse.com/PiEEG/designs).
