# Software Setup 

## Software Setup Options

Choose one of the following methods to install and run the **BodyPress** application:

### Option A: Work Directly in VR 

Install the native VR app from the Meta Quest Store to view and analyze your bio-signal data directly inside your headset.

* 📱 **App Store:** [BodyPress on Meta Quest Store](https://www.meta.com/en-gb/experiences/bodypress/1271355469389420/)

# Device test

## 1. Connect via the Live Demo

1. Open [pieeg.com](https://pieeg.com) and click **Try Live Demo**.
2. Make sure **Bluetooth is turned on** on your device.
3. Connect to the **`Aura VR`** device over **BLE**.

Once connected, live data begins streaming.

## 2. Test the Signal

1. Put Device on your Arm.
2. Watch the incoming data and run a few simple tests — muscle activity produces clear, visible signals.
3. Experiment with the **band-pass filter** and other settings.
4. **Save your data**, or test muscle through the built-in **mini-games**.
