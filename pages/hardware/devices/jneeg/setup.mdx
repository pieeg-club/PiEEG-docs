# How to Start

From a bare Jetson Nano to live EEG in your browser, in eight steps.

<Steps>

### Gather the parts

You need the JNEEG, a Jetson Nano, a 5 V / 3 A power bank, 8 electrodes with two ear clips, and a cap. See [What's in the Box](/hardware/devices/jneeg/required-equipment).

### Prepare the Jetson Nano

1. Flash NVIDIA's **JetPack** image for the Jetson Nano Developer Kit to the microSD card ([NVIDIA's guide](https://developer.nvidia.com/embedded/learn/get-started-jetson-nano-devkit)).
2. Boot it, finish the first-run setup and connect it to the internet (needed only for installing software).

### Enable SPI

SPI is off by default on the Jetson Nano. Turn it on with NVIDIA's tool:

```bash
sudo /opt/nvidia/jetson-io/jetson-io.py
```

In the menu: **Configure 40-pin header** → enable **spi1** → **Save and reboot**. After the reboot, check:

```bash
ls /dev/spidev0.0
```

Then let your user use SPI and GPIO without `sudo`, and log out and in again:

```bash
sudo groupadd -f spi
sudo usermod -aG spi,gpio "$USER"
```

### Mount the shield

1. **Shut down the Jetson** and unplug the power.
2. Line up the JNEEG with the 40-pin header so pin 1 matches pin 1.
3. Press it down evenly until every pin is seated.

![JNEEG mounted on the Jetson Nano](/images/hardware/2026/10/jneeg_on_nano.jpg)

### Connect the electrodes

| Connector | Electrode | Where it goes |
|---|---|---|
| **Channels 1–8** | 8 EEG electrodes in the cap | Scalp positions of the 10-20 system |
| **Reference** | Ear-clip electrode | One earlobe |
| **Bias** | Ear-clip electrode | The other earlobe |

![Electrodes, reference and bias on the JNEEG header](/images/hardware/2026/10/jneeg_pinout.png)

Details: [Electrodes & Pinout](/hardware/devices/jneeg/connections).

### Power on from the battery

1. Connect the monitor, wired keyboard and mouse. The monitor must be powered from the power bank or the Jetson.
2. Plug the **power bank** into the Jetson's Micro-USB power input.
3. The status LED on the JNEEG lights up.

<Callout type="error">
  The JNEEG has **no isolation** from its power supply. While electrodes are on a person, the Jetson, the shield and everything cabled to them must run **from the power bank only**.
</Callout>

### Install and start PiEEG Server

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install "pieeg-server[rpi]"

pieeg-server doctor           # check SPI, GPIO and dependencies
pieeg-server --device jneeg   # start streaming 8 channels
```

`--device jneeg` applies the Jetson Nano settings automatically (600 kHz SPI, GPIO on `/dev/gpiochip0`).

<Callout type="warning">
  PiEEG Server needs **Python 3.10 or newer**. JetPack 4 for the Jetson Nano ships Python 3.6, so install a newer Python first (or use an image with Python 3.10+). Prefer no install? The [Python scripts](/hardware/devices/jneeg/software#python-scripts) run on the stock Python.
</Callout>

### Check the signal

Open **http://localhost:1617** on the Jetson, or `http://<jetson-ip>:1617` from a battery-powered laptop. Click **Connect**, sit still and relax the face.

| Test | What you should see |
|---|---|
| **Sit still for 30 seconds** | All 8 channels settle. Flat lines or huge values mean a loose electrode. |
| **Close your eyes for 10 seconds** | Alpha (8–13 Hz) rises on the back-of-head channels, then drops when the eyes open |
| **Blink a few times** | Large slow spikes on the front channels |
| **Clench the jaw** | Bursts of high-frequency noise on all channels. That is muscle (EMG), not brain activity. |

</Steps>
