# PiEEG XR Intro

PiEEG XR is a Brain-Computer Interface (BCI) platform designed to bridge consumer-grade EEG hardware with WebXR-based Extended Reality (XR) environments. It enables real-time, neural-adaptive avatar behavior and interactions directly within a browser stack, without requiring proprietary SDKs or native application containers.

  <img src="https://github.com/Ildaron/PiEEG_XR/raw/main/Images/pieeg_xr_1.gif" width="30%" alt="IronBCI Demo">

By decoding continuous electroencephalography (EEG) signals into affective and cognitive states, PiEEG XR brings a user's internal neural correlates — such as attention, relaxation, and focus — into virtual environments like the Meta Quest browser or social VR platforms via **OSC**.

> This section covers the **hardware** and **how to get started**. For software setup and usage, see the [PiEEG Software page](#).

## Key Features

- **8 channels** of simultaneous biosignal acquisition
- Supports **EEG, EMG, and ECG** measurements
- Compatible with **dry and Ag/AgCl wet electrodes** via 2.54 mm pin-pitch connectors
- Works with the **PiEEG Server** for real-time streaming, recording, and integrations
