# Lessons

**One condition. One action.**

Every lesson is a single rule, so students see cause and effect straight away. Pick a lesson, press the controls and watch the program and the hardware react.

<Callout type="info">
  **Honest metrics:** The demos on the product page use simulated signals to show the idea. Real recordings are noisier, and the `focus` (`β / (β + θ)`) and `relax` (`α / (α + β)`) blocks are uncalibrated spectral band-power ratios — not measures of a student's attention, ability, or emotional state.
</Callout>

### Eyes closed, light on

Close your eyes and the alpha rhythm (8 to 13 Hz) over the back of the head grows. One rule turns that into a light.

```
forever
  if  alpha > 35%
      light D10 on
  else
      light D10 off
```

### Focus meter (beta / theta band-power ratio)

The `focus` block computes the uncalibrated band-power ratio `β / (β + θ)` and maps it onto the servo angle (`0–180°`), so the arm acts like a physical gauge of relative high-frequency power. Because beta power also increases with forehead or jaw muscle tension (sEMG) and shifts when alpha/theta change, teach students that the needle shows a **spectral power ratio**, not a score of how hard someone is thinking.

```
forever
  servo to  map(focus, 0–1 → 0–180°)
```

### Quiet room

Two readings, one action. If alpha is high and the motion sensor sees nobody, the screen asks for quiet.

```
forever
  if  alpha high  and  no motion
      screen "shh"
  else
      screen "hello!"
```

### Follow the knob

A warm-up with no headset. Turn the knob and the servo follows. The knob is a raw count from 0 to 1023, mapped onto 0 to 180 degrees.

```
forever
  servo to  map(knob, 0–1023 → 0–180°)
```

### Plant care

The soil sensor reads a raw count. When it falls below the line, the soil is dry and the buzzer sounds.

```
forever
  if  soil < 300
      buzzer on
  else
      buzzer off
```

### Blink is not a thought

Blinks and jaw clenches are muscle, and they show up in the EEG as big swings in RMS and gamma. This rule flags them on the screen.

```
forever
  if  RMS > 45 µV  or  gamma > 22%
      screen "artifact!"
  else
      screen "EEG ok"
```

## Teaching notes

- Start every class with **Follow the knob**: it works without a headset and teaches mapping.
- Use **Blink is not a thought** early, so students learn that a big signal is not always brain activity.
- Never present `focus` (`β / (β + θ)`) or `relax` (`α / (α + β)`) as a score of a student's ability, attention, or mood — explain them as ratios of frequency band power.
