# PiEEG Software

PiEEG Server turns supported PiEEG hardware into a real-time EEG streaming platform with a browser dashboard, WebSocket API, CSV recording, Lab Streaming Layer output, VRChat OSC, and automation hooks.

For browser apps that talk to a board directly (no server), see the
[JavaScript SDK](/software/api/javascript-sdk) — Web Bluetooth / Web Serial with
built-in filtering and band-power analysis.

The classroom lab is **[octoBridge](/software/octobridge)** at [octobridge.pieeg.com](https://octobridge.pieeg.com/) — Octopus-16 over Bluetooth plus the octoBio Kit over USB, with block programs and in-browser firmware flashing.

For Garmin smartwatch users, **[octoWatch](/software/octowatch)** ([Garmin Connect IQ Store](https://apps.garmin.com/apps/8e994535-c853-45ca-abe3-ccef61119c8b)) streams and visualizes live 16-channel 250 SPS EEG from Octopus-16 directly on your wrist over BLE.
