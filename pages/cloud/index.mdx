# PiEEG Cloud

**[cloud.pieeg.com](https://cloud.pieeg.com) is the browser-based PiEEG platform.** Open it in Chrome or Edge and stream directly from hardware over Web Bluetooth or Web Serial with no Python installation and no local backend required. Packet decoding, DSP filtering, FFT spectral analysis, 3D topography, and every experience run client-side in the browser tab.

<Callout type="info">
  Point a Chromium browser at **[cloud.pieeg.com](https://cloud.pieeg.com)**, pick a signal source in the Session Lobby, and start streaming. Raw acquisition and signal conditioning execute locally in your browser.
</Callout>

## What runs in the cloud

The cloud platform is built from the [PiEEG-server-cloud](https://github.com/pieeg-club/PiEEG-server-plus) project and ships browser applications plus an optional local P2P gateway:

| App | What it is | Where it runs |
|-----|-----------|---------------|
| **Dashboard** | Live waveforms, spectral analysis, 3D topographic maps, session playback, WebXR view, and the [experiences gallery](/software/features/experiences). | Browser: [cloud.pieeg.com](https://cloud.pieeg.com) |
| **[BrainFlow Devices](/cloud/brainflow)** | Browser-native WebBLE and WebSerial drivers for 17 BrainFlow-compatible third-party boards (`BoardIds`), with Nyquist-adaptive DSP conditioning. | Browser: [cloud.pieeg.com/lobby](https://cloud.pieeg.com/lobby) |
| **[Live Lab (Bio-Pen)](/cloud/live-lab)** | Programmable 15 Hz JavaScript signal pipeline, graded curriculum briefs (`check()`), head-to-head Decoder Arena (`loroCV`), and one-click `/lab/:id` permalinks. | Browser: [cloud.pieeg.com/lab](https://cloud.pieeg.com/lab) |
| **[Buddy](/cloud/buddy)** | Browser-native EEG copilot and AI agent: live brain panel, a tool-using LLM that reads your brain state (BYO API key), and guided pattern training. | Browser: [buddy.pieeg.com](https://buddy.pieeg.com/) |
| **[Local Bridge](/cloud/local-bridge)** | Standalone 5 MB Rust gateway that receives frames from the browser over a P2P WebRTC data channel and forwards them locally as OSC packets. | Local binary (`127.0.0.1` / LAN) |

<Callout type="info">
  Need Raspberry Pi **SPI** shield acquisition or native **Lab Streaming Layer (LSL)** outlets? Run the self-hosted [PiEEG Server](/software) on your device.
</Callout>

## Connect a device

`cloud.pieeg.com` communicates with hardware directly from the browser using the **Web Bluetooth** and **Web Serial** APIs. The Session Lobby organizes hardware into two tabs:

<Steps>
### PiEEG Devices (Always Free)

Connect any first-party PiEEG wireless or USB board:
- **Web Bluetooth**: **IronBCI** (8 ch), **IronBCI-16** (16 ch), **PiEEG XR** (8 ch), **PiEEG XR-16** (16 ch), **Octopus 16** (16 ch), or **Aura VR** (8-ch EMG + 6-axis IMU).
- **Web Serial (USB)**: **IronBCI-32** (32 ch @ 500 Hz) or **Kraken-48** (48 ch @ 250 Hz).

### BrainFlow Devices (Free for Launch)

Switch to the **[BrainFlow Devices](/cloud/brainflow)** tab to connect 17 third-party boards natively over Web Bluetooth or Web Serial (including Ganglion, Muse 2 / S / Athena / 2016, BrainAlive, AAVAA V3, Cyton, Cyton + Daisy, FreeEEG32, Knight, Knight IMU, Enophone, and Explore 4 / 8 / +8 / +32).

### Simulated & Programmable Demos

Use the **No device? Try a demo** bar at the bottom of the lobby to launch a client-side `8-ch`, `16-ch`, `32-ch`, `Aura`, or programmable `/mock` studio stream without hardware.
</Steps>

### Supported First-Party Sources

| Source | Channels | Sample Rate | Transport |
|--------|----------|-------------|-----------|
| IronBCI / PiEEG XR | 8 | 250 Hz | Web Bluetooth (BLE) |
| IronBCI-16 / PiEEG XR-16 | 16 | 250 Hz | Web Bluetooth (BLE) |
| Octopus 16 | 16 | 250 Hz | Web Bluetooth (BLE) |
| Aura VR | 8 EMG + IMU | 250 Hz | Web Bluetooth (BLE) |
| IronBCI-32 | 32 | 500 Hz | Web Serial (USB) |
| Kraken-48 | 48 | 250 Hz | Web Serial (USB) |
| Simulated Demo | 8 / 16 / 32 / Aura / Custom | 250 / 500 Hz | In-browser synthesis |

For third-party boards, see the full [BrainFlow Devices compatibility matrix](/cloud/brainflow).

<Callout type="warning">
  Web Bluetooth and Web Serial require a Chromium-based browser (Chrome, Edge, Brave, Opera) over HTTPS or `localhost`. Firefox, Safari, and iOS/iPadOS browsers (WebKit) do not expose these APIs.
</Callout>

## Browser vs. self-hosted

| | **Cloud (cloud.pieeg.com)** | **Self-hosted [PiEEG Server](/software)** |
|---|---|---|
| Install | None | Python / Raspberry Pi setup |
| Boards | PiEEG BLE/USB boards + 17 [BrainFlow WebBLE/WebSerial boards](/cloud/brainflow) | + Raspberry Pi SPI shields (PiEEG / PiEEG-16) |
| DSP & FFT | In-browser (`DspChain` + Web Worker FFT) | On the server |
| OSC output | Via [Local Bridge](/cloud/local-bridge) (WebRTC P2P) | Built-in |
| LSL output | Self-hosted server | Built-in |
| Access | Free with PiEEG devices; BrainFlow tab free during launch | MIT open-source |

## Privacy

Acquisition, packet decoding, filtering, and spectral analysis on `cloud.pieeg.com` execute locally inside your browser tab. Data is only transmitted outside the tab when you explicitly start a Live Relay, upload a recording to the Cloud Library, or connect [Buddy](/cloud/buddy) to your chosen LLM provider.
